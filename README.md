# 禅語・格言デイリーウィズダムカウントダウン

毎日の格言・禅語をランダム表示し、今日の終わりまでのカウントダウンと瞑想タイマーが一体化したウェルネスアプリ。

## 機能

- 禅語・名言53件をハードコード（日本語・英語対訳・出典付き）
- 毎日0:00リセットのデイリー格言表示（localStorageで今日の格言を記憶）
- 今日の終わり（23:59:59）まで時分秒カウントダウン表示
- 瞑想タイマー（5/10/15/20分選択、Web Audio APIによるベル音）
- SVGプログレスリングでタイマー進捗を視覚化
- ハートマークでお気に入り保存・一覧表示

## 技術仕様

- バニラJS / Tailwind CDN / Web Audio API / インラインSVG
- XSSガード実装済み（escHtml関数）
- レスポンシブ対応
- 全インタラクティブ要素にaria-label付与
